# 증상 척도·선별 설문 Symptom Scales & Screening Questionnaires

{% hint style="info" %}
작성 예정 : NRS·VAS, DN4·painDETECT, FSS, K-ESS 외 수면 척도는 감각·수면 검사 참조

## <mark style="color:green;">우울 선별 척도 (PHQ-2·PHQ-9·노인우울척도 GDS)</mark>

**무엇을 보는가**

* PHQ-9 : DSM 주요우울장애 9개 증상의 지난 2주 빈도 - 선별·중증도·치료 경과
* PHQ-2 : PHQ-9의 첫 2문항(흥미 저하, 우울감)으로 하는 1단계 선별
* GDS(노인우울척도) : 신체 증상 문항을 줄인 고령자용 예/아니오 척도 - 15문항 단축형이 흔함

**언제 시행하는가**

* 우울 증상, 설명되지 않는 신체 증상·피로·불면, 만성 질환, 산후, 고령자
* 치료 시작 시 기저 점수를 기록하고 추적마다 같은 도구로 반복
* 우울 증상이 있으면 자살 위험을 반드시 평가 (무증상 성인의 일률적 자살 위험 선별은 근거 불충분)

**검사 방법**

* 각 문항 : 전혀 아니다 0점, 여러 날 1점, 일주일 이상 2점, 거의 매일 3점
* PHQ-2 양성이면 PHQ-9 시행

**해석·절단값**

* PHQ-2 : ≥3점 민감도/특이도 72%/85%, ≥2점 91%/67% <mark style="color:$info;">\[JAMA 2020]</mark> - 민감도를 중시하면 ≥2점에서 PHQ-9
* PHQ-9 : ≥10점 기준 민감도 88%, 특이도 85% <mark style="color:$info;">\[BMJ 2019]</mark>
  * 중증도 : 0\~4점 최소, 5\~9점 경도, 10\~14점 중등도, 15\~19점 중등도-중증, 20\~27점 중증
* 9번 문항(죽음·자해 생각)이 1점 이상이면 총점과 관계없이 그 자리에서 자살 위험 면담
* GDS-15 : 대개 ≥5\~6점이면 추가 평가 (국내 판본의 기준 확인)

**위양성·위음성**

* 선별 양성은 진단이 아님 - DSM-5-TR 기준 면담, 양극성장애·물질·신체질환(갑상선저하증 등) 감별
* 신체 질환이 있으면 피로·수면·식욕 문항이 점수를 올림
* 항우울제 시작 전 과거 조증·경조증을 확인 - 필요하면 MDQ (☞ 기분장애 질문지)

## <mark style="color:green;">에든버러 산후우울증 척도 EPDS</mark>

**무엇을 보는가**

* 임신 중과 출산 후 1년 동안의 우울·불안 증상 - 최근 7일 기준 10문항 자기보고

**언제 시행하는가**

* 산전 진찰과 산후 방문(영유아 검진 포함)에서 반복 선별
* 산후 우울감·불안·수면 문제·영아 돌봄 어려움을 호소할 때

**검사 방법**

* 문항마다 응답 문구와 채점 방향이 다르므로 검증된 공식 한국어판 양식을 그대로 사용

**해석·절단값**

* ≥13점을 흔히 선별 양성으로 사용 (한국판 검증 연구는 ≥10점)
* 10번 자해 문항이 1점 이상이면 총점과 무관하게 즉시 자살 위험 면담

**위양성·위음성**

* 총점만으로 진단하거나 중증도를 정하지 않음 - 진단 면담 필요
* 산후 갑상선염, 빈혈·철결핍, 수면 부족이 비슷한 증상을 만듦 - TSH, CBC ± ferritin
* PHQ-9도 사용 가능 - 같은 도구로 반복 측정하여 변화를 추적

***

## <mark style="color:green;">기분장애 질문지 Mood Disorder Questionnaire, MDQ</mark>

**무엇을 보는가**

* 과거 조증·경조증 증상 13문항 + 동시 발생 여부 + 기능 문제 정도 - 양극성장애 선별

**언제 시행하는가**

* 우울 삽화 환자에서 항우울제를 시작하기 전, 특히 젊은 발병·반복 삽화·가족력·항우울제 후 들뜸이 있을 때

**검사 방법**

* 자기보고; 가능하면 가족의 관찰을 함께 확인

**해석·절단값**

* 원판 기준 : 13문항 중 ≥7개 예 + 여러 증상이 같은 시기에 발생 + 중등도 이상 문제 - 양성
* 양성이면 정신건강의학과 평가 - 항우울제 단독 시작을 보류

**위양성·위음성**

* 경조증(양극성 II형)은 민감도가 낮음 - 음성이어도 병력상 의심되면 면담
* 경계성 성격장애·물질 사용·ADHD에서 위양성

***

## <mark style="color:green;">불안·공황 척도 (GAD-2·GAD-7·PDSS-SR)</mark>

**무엇을 보는가**

* GAD-7 : 지난 2주의 불안 증상 7문항 - 범불안장애 선별·중증도·경과 (공황·사회불안·PTSD도 일부 포착)
* GAD-2 : GAD-7의 첫 2문항 선별
* PDSS-SR(공황장애 중증도 척도 자기보고판) : 지난 1주 발작 빈도·고통, 예기불안, 광장공포적 회피, 신체감각 회피, 직업·사회 기능 7문항

**언제 시행하는가**

* 불안·걱정·신체 증상(두근거림, 어지럼, 위장 증상)을 반복 호소할 때, 우울 선별 양성일 때 함께
* 공황장애 진단 후 기저 중증도 기록과 치료 경과

**검사 방법**

* GAD-7 : 각 0\~3점, 0\~21점
* PDSS-SR : 각 0\~4점, 0\~28점

**해석·절단값**

* GAD-2 : ≥3점이면 GAD 의심 (원연구 민감도 86%, 특이도 83%; 메타분석에서는 약 76%/81%) - 0\~2점이어도 의심이 강하면 GAD-7
* GAD-7 : 5·10·15점이 경도·중등도·중증의 기준; ≥10점이면 추가 진단 평가
* PDSS 중증도 (임상의 평정판 기준, 자기보고판은 참고) <mark style="color:$info;">\[Depress Anxiety 2009]</mark>
  * 광장공포 없음 : 0\~1 정상, 2\~5 경계, 6\~9 경도, 10\~13 중등도, ≥14 현저
  * 광장공포 있음 : 3\~7 경계, 8\~10 경도, 11\~15 중등도, ≥16 현저

**위양성·위음성**

* 척도는 확진 도구가 아님 - 치료 결정은 진단, 기능 손상, 자살 위험, 동반 질환을 함께 판단
* 갑상선항진증, 부정맥, 저혈당, 카페인·약물·금단 등 신체 원인을 감별
* PDSS 임상의 평정판(지난 1개월)과 자기보고판(지난 1주)을 섞어 비교하지 않음

***

## <mark style="color:green;">신체증상 척도 (PHQ-15·SSS-8·SSD-12)</mark>

**무엇을 보는가**

* PHQ-15·SSS-8 : 신체 증상 부담 (신체 질환에 의한 증상도 포함)
* SSD-12 : 신체 증상에 대한 과도한 생각·감정·행동 - DSM-5-TR 신체증상장애의 '기준 B'

**언제 시행하는가**

* 여러 신체 증상이 지속되고 반복 검사·잦은 방문이 이어질 때, 경과 추적

**검사 방법**

* PHQ-15 : 최근 4주 15개 증상, 각 0\~2점 (0\~30점)
* SSS-8 : 최근 1주 8개 증상 영역(위장, 요통, 사지·관절, 두통, 흉통·호흡곤란, 어지럼, 피로, 입면 곤란), 각 0\~4점 (0\~32점)
* SSD-12 : 생각·감정·행동 3영역 12문항, 각 0\~4점 (0\~48점)

**해석·절단값**

* PHQ-15 : 5·10·15점이 경도·중등도·고도 부담의 기준
* SSS-8 : 0\~3 없음/최소, 4\~7 낮음, 8\~11 중간, 12\~15 높음, 16\~32 매우 높음
* SSD-12 : 한국 정신건강의학과 외래 최적 절단점 ≥29점 <mark style="color:$info;">\[Psychiatry Investig 2024]</mark>

**위양성·위음성**

* 점수 조합만으로 신체증상장애·질병불안장애·신체 질환을 구분하지 못함
* 신체증상장애 진단이 있어도 새 증상·객관적 이상은 일반 환자처럼 평가
* 중증 질환 가능성이 낮은데 안심시키려는 반복 검사는 위양성·우연종과 건강 불안을 늘림

***

## <mark style="color:green;">두통 영향 척도와 두통 일기 (HIT-6·MIDAS)</mark>

**무엇을 보는가**

* 두통 일기 : 빈도, 지속 시간, 강도, 동반 증상, 복용 약물, 유발 요인, 월경과의 관계 - 진단·약물과용 확인·치료 효과
* HIT-6 : 통증·사회·역할·인지 기능·심리적 고통·활력 6문항 - 두통으로 인한 기능 장애
* MIDAS : 지난 3개월 두통으로 잃거나 생산성이 절반 이하로 떨어진 일수 5문항

**언제 시행하는가**

* 반복 두통의 진단과 예방치료 결정, 치료 반응 추적

**검사 방법**

* 두통 일기는 매일 취침 전, 약 8주 기록 ('대한두통학회 두통일기' 앱 활용 가능)

**해석·절단값**

* HIT-6 (36\~78점) : 36\~49 영향 없거나 경미, 50\~55 중등도, 56\~59 상당함, 60\~78 심각
* MIDAS : 0\~5 (Ⅰ) 장애 없거나 미약, 6\~10 (Ⅱ) 경도, 11\~20 (Ⅲ) 중등도, ≥21 (Ⅳ) 중증
* 예방치료는 단일 점수가 아니라 월 두통일수, 기능 장애, 급성기 치료 반응, 환자 선호로 결정

**위양성·위음성**

* 회상 편향 - 일기가 MIDAS보다 정확
* 진통제 복용 일수 기록이 빠지면 약물과용두통을 놓침

***

## <mark style="color:green;">번아웃 평가 도구 (MBI·단일 문항·국내 척도)</mark>

**무엇을 보는가**

* 직무 관련 만성 스트레스로 인한 소진, 냉소(비인격화), 효능감 저하

**언제 시행하는가**

* 직무 스트레스·소진 호소의 상태 평가, 조직 수준 조사·모니터링

**검사 방법**

* MBI(Maslach Burnout Inventory, 유료) : MBI-HSS(대인서비스 직종; 정서적 소진·비인격화·개인적 성취감)와 MBI-GS(일반 직종; 소진·냉소·효능감)
* 단일 문항 번아웃 척도 : MBI 정서적 소진과 상관이 검증된 간이 선별 <mark style="color:$info;">\[JGIM 2015]</mark>
* 국내 척도 : K-CBI(코펜하겐 소진척도), K-OLBI(올덴버그), K-BAT(직무소진평가척도)

**해석·절단값**

* 개인의 번아웃을 진단하거나 약물치료·병가를 결정하는 보편적 절단점은 없음 - MBI 4판은 과거 규준 절단점을 삭제
* 개인적 성취감은 점수가 낮을수록 번아웃을 시사 (다른 소척도와 채점 방향이 반대)

**위양성·위음성**

* 번아웃 척도로 우울증·불안장애를 배제하지 못함 - PHQ-9·GAD-7을 함께
* 비인격화는 해리 증상인 이인증이 아님

***

## <mark style="color:green;">요통 위험도·기능 척도 (STarT Back·ODI·RMDQ)</mark>

**무엇을 보는가**

* STarT Back : 신체 요인(통증 부위·방사통·기능 제한)과 심리사회 요인(두려움-회피, 불안·우울, 파국적 사고) 9문항 - 만성화 위험도 층화
* ODI(Oswestry 장애지수)·RMDQ(Roland-Morris 장애 설문) : 요통으로 인한 기능 장애

**언제 시행하는가**

* 초진 시 위험도 층화 고려 <mark style="color:$info;">\[NICE NG59]</mark>, 치료 경과 추적

**검사 방법**

* STarT Back : 9문항 (총점 0\~9점, 심리사회 하위점수 0\~5점)
* ODI : 통증 강도·자기관리·들기·걷기·앉기·서기·수면·성생활·사회생활·여행 10개 영역, 각 0\~5점 → 백분율

**해석·절단값**

* STarT Back : 총점 ≤3점 저위험; ≥4점이면서 심리사회 하위점수 ≤3점 중위험, ≥4점 고위험
  * 저위험 : 안심·활동 유지 교육
  * 중위험 : 운동·재활
  * 고위험 : 운동·재활 + 심리적 개입을 포함한 다학제 접근
* ODI : 0\~20% 최소, 21\~40% 중등도, 41\~60% 심한 장애, 61\~80% 매우 심함, 81\~100% 와상 또는 과장

**위양성·위음성**

* 위험도 도구의 판별력은 제한적(C statistic 0.59\~0.71) - 단독으로 치료를 결정하지 않음 <mark style="color:$info;">\[JAMA 2026]</mark>
* Red Flags 평가를 대신하지 않음

***

## <mark style="color:green;">음주 선별과 알코올 생체지표 (AUDIT-C·AUDIT-K·SASQ·GGT·CDT·PEth)</mark>

**무엇을 보는가**

* 위험음주·알코올 사용 장애(AUD) 가능성 선별
* 알코올 생체지표 : 최근 음주의 객관적 보조 증거

**언제 시행하는가**

* 성인 정기 진료, 간효소 상승·고혈압·불면·우울·외상 등 음주 관련 가능 문제
* 생체지표 : 최근 음주를 객관화할 임상적 필요가 있을 때 선택적으로

**검사 방법**

* AUDIT-C : WHO AUDIT 첫 3문항(빈도, 음주일 잔 수, 폭음 빈도) 각 0\~4점, 총 0\~12점 - 1 drink = 순수 알코올 10 g (WHO)
* AUDIT-K : 국내 검증 10문항 - 해당 도구의 표준잔·문항을 그대로 사용하고 다른 표준잔으로 바꾸지 않음
* SASQ 단일 질문 (14 g 기준) : "지난 1년 동안 하루에 여성 4잔, 남성 5잔 이상 마신 날이 몇 번 있었습니까?" - 1회 이상이면 추가 평가
* CAGE : 평생 알코올 문제 탐지에 적합 - 현재 위험음주는 AUDIT-C·SASQ 우선

**해석·절단값**

* AUDIT-C : 남 ≥4점, 여 ≥3점 (미국 일차진료 연구) - 국내 한국어판에 같은 성능을 가정하지 않음
* AUDIT-K (남 / 여) : 0\~9 / 0\~5 낮은 점수, 10\~19 / 6\~9 고위험 음주, ≥20 / ≥10 AUD 의심 <mark style="color:$info;">\[국립정신건강센터 2019]</mark>
* 양성 선별 후 DSM-5-TR 11개 기준(12개월 내 ≥2개 : 2\~3 경증, 4\~5 중등증, ≥6 중증)과 금단 위험 평가 (☞ 알코올 금단 위험·중증도 평가)

**위양성·위음성**

* AUDIT-C·AUDIT-K·CAGE는 선별 도구이며 AUD 진단 도구가 아님
* 낮은 점수가 안전한 음주나 AUD 부재를 확정하지 않음 - 과거 AUD·금단력·임신은 점수와 관계없이 추가 평가
* 생체지표는 단독 진단에 쓰지 않음; 간효소가 정상이어도 진행된 알코올 관련 간질환을 배제하지 못함

**급여**

* CDT : 2021년 8월부터 누-477 탄수화물 결핍 트랜스페린으로 선별급여(본인부담 90%) - 최신 적용기준과 시행기관 확인
* PEth : 국내 급여·시행기관이 명확하지 않음 - 의뢰 전 확인

## <mark style="color:green;">알코올 금단 위험·중증도 평가 (PAWSS·CIWA-Ar)</mark>

**무엇을 보는가**

* PAWSS : 아직 심한 증상이 없는 환자의 복잡 금단(발작·섬망) 위험 예측
* CIWA-Ar : 현재 금단 증상의 중증도와 치료 반응 (10개 항목)

**언제 시행하는가**

* AUD 또는 고위험 음주자의 감량·금주 계획, 마지막 음주 후 진전·발한·불안·빈맥

**검사 방법**

* 마지막 음주 시각, 과거 금단 발작·섬망, 금단 횟수, 다른 진정수면제 사용, 동반 질환을 먼저 확인
* 저혈당·감염·갑상선항진증 등 유사 상태를 함께 확인 (혈당, 전해질, Mg, P, LFT, CBC)
* Wernicke 뇌병증이 의심되면 thiamine 농도를 기다리지 않고 치료

**해석·절단값**

* PAWSS ≥4점 : 복잡 금단 고위험 <mark style="color:$info;">\[Alcohol Alcohol 2015]</mark> - 원 검증은 입원 환자
* CIWA-Ar (ASAM 예시) : ＜10 경증, 10\~18 중등도, ≥19 중증 - 기관마다 투약 역치가 다름

**위양성·위음성**

* CIWA-Ar는 발작·섬망을 예측하거나 치료 장소를 정하는 단독 도구가 아님 (ASAM 2020)
* 감염·통증·불안·다른 약물 금단은 점수를 높이고, β차단제·clonidine은 낮춤
* **섬망 환자에게 CIWA-Ar를 쓰지 않음** - 의사소통이 어렵거나 중환자는 RASS 등 객관적 평가
* 중증 금단 위험 : 과거 섬망·발작, 반복 금단, 고령, 임신, 중대한 동반 질환, 다른 진정제 의존, 보호자·매일 재평가 불가

***

## <mark style="color:green;">니코틴 의존도 평가 (FTND·HSI·호기 일산화탄소·cotinine)</mark>

**무엇을 보는가**

* FTND(Fagerström) 6문항 0\~10점 : 니코틴 의존도
* HSI : FTND 1번(첫 흡연 시간)과 4번(하루 흡연량) 합계 0\~6점
* 호기 CO·cotinine : 흡연·니코틴 노출의 객관적 보조 지표

**언제 시행하는가**

* 금연치료 시작 전 평가, 금연 상태 확인과 동기 강화

**검사 방법**

* 궐련, 궐련형 전자담배, 액상형 전자담배, 니코틴 파우치 등 모든 제품과 이중 사용을 확인
* FTND 배점 : 기상 후 첫 흡연 5분 이내 3, 6\~30분 2, 31\~60분 1, ＞60분 0; 하루 ≤10개비 0, 11\~20 1, 21\~30 2, ≥31 3; 나머지 4문항 각 예 1점

**해석·절단값**

* FTND : 0\~3 낮음, 4\~6 중간, 7\~10 높음 (실무 분류)
* HSI ≥4 : 의존도 높음

**위양성·위음성**

* FTND가 낮아도 금연치료를 제공하며 진단 기준(DSM-5-TR)을 대신하지 않음
* 궐련용 척도를 전자담배 사용량에 그대로 적용하지 않음
* 액상형 전자담배 단독 사용자는 연소가 없어 호기 CO가 비흡연자 수준 - 정상 CO로 니코틴 사용을 배제하지 않음
* cotinine은 NRT·전자담배에서도 양성

***

## <mark style="color:green;">피로 척도와 ME/CFS 진단 기준 (Chalder Fatigue Scale·NAM 2015·NICE)</mark>

**무엇을 보는가**

* Chalder Fatigue Scale(CFQ-11) : 신체 피로 7문항 + 정신 피로 4문항의 정도와 변화
* NAM/IOM 2015·NICE NG206 : 근육통성뇌척수염/만성피로증후군(ME/CFS) 임상 진단 기준

**언제 시행하는가**

* 지속되는 피로로 기능이 떨어진 환자의 경과 추적
* 활동 후 악화(PEM)·비회복성 수면·인지장애가 동반된 장기 피로

**검사 방법**

* CFQ-11 : 지난 1개월을 평소와 비교해 각 0\~3점 (Likert 총점 0\~33) - 장기 환자는 발병 전 상태를 기준으로; 저작권 척도이므로 검증된 판본을 일관되게 사용
* PEM 확인 : 1\~2주간 활동과 활동 후 48시간 이상의 증상을 함께 기록
* 기본 검사(환자별 우선순위) : CBC 감별, ESR·CRP, 전해질·Ca·P, 혈당·A1C, LFT, 신기능, TSH·free T4, 철 검사, 소변검사; 단서에 따라 셀리악 선별, CK, B12·엽산·Vit D
* 기립불내성 의심 : 10분 능동 기립 검사 또는 NASA lean test (☞ 능동 기립 검사) - 중증 환자는 PEM·실신 위험에 주의

**해석·절단값**

* NAM/IOM 2015 : 6개월 초과 기능 저하 + 피로, PEM, 비회복성 수면 모두 + 인지장애 또는 기립불내성 중 ≥1 - 증상이 최소 절반의 시간 동안 중등도 이상이 아니면 재고
* NICE NG206 : 3개월, 쇠약성 피로·PEM·비회복성 수면·인지장애가 모두 지속 (기립불내성은 필수 아님); 성인 6주, 소아·청소년 4주 지속 시 의심
* 두 기준은 기간과 구성이 달라 섞어 적용하지 않음

**위양성·위음성**

* 설문 점수만으로 ME/CFS를 진단하거나 회복을 판정하지 않음 - CFQ는 PEM·기립불내성을 반영하지 못함
* ME/CFS를 확진하는 검사·바이오마커는 없음; 철결핍·갑상선질환·수면장애·POTS·우울증은 공존 가능
* 임상적 의심 없는 광범위 감염·자가면역 검사는 위양성과 불필요한 치료를 부름
* SPECT·PET은 일상 진단검사가 아님; 2일 연속 CPET는 재현성이 일관되지 않고 증상 악화 위험이 있어 제한적 상황에서 전문기관만
