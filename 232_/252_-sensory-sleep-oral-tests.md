## <mark style="color:green;">진료실 안과 기본 검사 (시력·동공·형광 염색·Seidel·눈꺼풀 뒤집기·안압)</mark>

**무엇을 보는가**

* 충혈·통증·외상 환자에서 응급 안과 질환(급성 폐쇄각녹내장, 각막염·각막궤양, 포도막염, 안구 개방손상, 안와연조직염)을 가려냄
* fluorescein 염색 : 각막 상피 결손(찰과상·이물·궤양), 수지상 병변(HSV)
* Seidel test : 각막·공막 상처를 통한 방수 누출 - 안구 개방손상

**언제 시행하는가**

* 눈 충혈, 눈 통증·눈부심, 시력 변화, 이물감, 눈 외상, 콘택트렌즈 착용자의 충혈

**검사 방법**

1. 화학 손상이면 검사보다 세척을 먼저; 안구 개방손상이 의심되면 조작을 멈추고 보호대 적용
2. 시력 : 안경을 쓴 상태로 양안 각각 측정, 저하되면 핀홀로 굴절 이상과 구분 - 처치 전에 기준치 기록
3. 눈꺼풀·안와 주위, 안구운동·복시·운동 시 통증, 안구돌출
4. 동공 : 크기·모양, 직접·간접 대광반사, swinging flashlight test로 상대구심동공운동장애(RAPD)
5. 충혈 양상, 분비물, 각막 투명도·백색 침윤, 전방출혈·전방축농
6. fluorescein 염색 후 코발트블루 빛(또는 세극등) 관찰; 선상 찰과상·이물이 의심되면 위눈꺼풀을 뒤집어 확인 (개방손상이 배제된 경우만)
7. 안압 : 안구 개방손상이 배제된 경우에만 측정

**해석·절단값**

* 형광 염색
  * 선상·지도 모양 결손 : 찰과상 (위눈꺼풀 이물이면 세로 선상 결손)
  * 말단이 팽대한 수지상 병변 : HSV 각막염 - 당일 안과, 스테로이드 점안 금지
  * 미만성 점상 염색 : 광각막염(용접·자외선, 6\~12시간 후 양안), 건성안
  * 콘택트렌즈 착용자의 백색 침윤·염색 : 감염성 각막염 - 당일 안과
* Seidel 양성 : 형광 색소가 방수에 희석되어 흘러내림 - 개방손상, 즉시 의뢰
* 교감성 눈부심(반대쪽 눈에 빛을 비출 때 환측 통증) : 전방포도막염 시사
* 지속되는 시력 저하, RAPD, 동공 변형은 단순 결막염이 아님

**위양성·위음성**

* Seidel 음성이 안구 관통을 배제하지 못함 - 작은 상처는 저절로 막힘; 고속 금속 파편·날카로운 물체 손상이면 결과와 무관하게 즉시 의뢰
* 분비물의 색·성상만으로 바이러스성과 세균성 결막염을 구분하지 못함
* 안압계가 없을 때 안구 촉진은 보조 단서일 뿐 확진·배제 검사가 아님 (외상·개방손상 의심 시 금지)
* 안구 내 이물 : 비조영 박절편 안와 CT - 나무 등 유기물은 CT에서 놓칠 수 있고, 금속 이물 의심 시 MRI 금기; 단순 X선은 배제 목적으로 권장하지 않음

## <mark style="color:green;">안구건조 검사 (OSDI-6·눈물막 파괴 시간·안구 표면 염색·Schirmer)</mark>

**무엇을 보는가**

* 건성안(DED) : 증상 + 눈물막·안구 표면 항상성 이상 <mark style="color:$info;">\[TFOS DEWS III 2025]</mark>
* 눈물막 파괴 시간(NIBUT·FBUT) : 눈물막 안정성
* 안구 표면 염색 : 각막(fluorescein)·결막(lissamine green)·안검연 손상
* 눈물 삼투압 : 눈물의 고삼투압
* Schirmer 검사 : 수성 눈물 분비량

**언제 시행하는가**

* 이물감·작열감·눈 피로·시야 흐림·눈물 과다를 반복 호소할 때
* 쇼그렌병이 의심될 때 (구강건조, 침샘 종창, 관절통)

**검사 방법**

* 증상 선별 : OSDI-6 (지난 1개월, 6문항, 각 0\~4점, 0\~24점)
* 덜 침습적인 검사부터 : NIBUT → 삼투압 → FBUT(형광 색소 최소량) → 염색
* Schirmer : 점안 마취 없이 아래눈꺼풀 바깥 1/3에 여과지를 걸고 5분 후 젖은 길이 측정

**해석·절단값**

* OSDI-6 ≥4점 : 건성안 의심 (0\~3 정상, 4\~8 경증\~중등도, 9\~24 중증 증상) <mark style="color:$info;">\[Am J Ophthalmol 2025]</mark>
* 증상 양성 + 다음 중 1가지 이상 양성이면 건성안 진단
  * NIBUT ＜10초
  * FBUT ＜5초 (NIBUT을 할 수 없을 때)
  * 눈물 삼투압 ≥308 mOsm/L 또는 양안 차이 ＞8 mOsm/L (TearLab 기준)
  * 각막 형광 점상 ＞5개, 결막 lissamine green 점상 ＞9개, 또는 안검연 염색 길이 ≥2 ㎜·폭 ≥25%
* Schirmer ≤5 ㎜/5분 : 수성 눈물 결핍 기전 시사 (건성안 진단의 필수 검사는 아님)

**위양성·위음성**

* 검사 1가지 음성으로 건성안을 배제하지 않음 - 최소 2가지 항상성 지표를 평가
* 형광 색소를 많이 넣으면 FBUT이 짧아짐
* 쇼그렌병 분류기준에서 Schirmer·안구 염색은 일부 항목일 뿐 - 자가항체(anti-SSA/Ro)와 함께 판단

* 시력 저하·떠다니는 물체·시야 가림이 새로 생기면 선별 주기와 무관하게 신속 의뢰

**위양성·위음성**

* 비산동 사진·AI 판독은 주변부 병변과 황반부종을 놓칠 수 있음 - 포괄적 검진의 완전한 대체가 아님
* 백내장 등으로 매체가 혼탁하면 판독 불가

## <mark style="color:green;">이경 검사와 고막운동성계측 (공기이경·tympanometry)</mark>

**무엇을 보는가**

* 공기이경(pneumatic otoscopy) : 고막 위치·색·투명도와 압력 변화에 따른 움직임 - 중이 삼출액(MEE)
* 고막운동성계측(tympanometry) : 외이도 압력 변화에 따른 고막 탄성(compliance) - 중이 삼출액, 이관 음압, 천공

**언제 시행하는가**

* 급성 중이염 의심(귀 통증, 발열, 보채는 소아)
* 귀 먹먹함·충만감, 청력 저하, 이관 기능장애 의심
* 이경 소견이 불확실할 때 tympanometry로 MEE 확인

**검사 방법**

* 이경 : 귀지를 제거하고 밀폐되는 이경 귀경으로 고막을 가볍게 가압 - 움직임 관찰
* tympanometry : 외이도를 탐침으로 밀폐하고 자동 측정; 외이도 용적을 함께 확인

**해석·절단값**

* 급성 중이염 : MEE + 중등도\~고도 고막 팽륜, 또는 새로운 이루(외이도염 아님), 또는 경도 팽륜 + 48시간 이내 귀 통증 또는 고막의 강한 발적 <mark style="color:$info;">\[AAP 2013]</mark>
  * 고막 팽륜이 가장 신뢰할 만한 소견
* tympanometry

* Valsalva 통기 여부나 ETDQ-7 점수만으로 이관 기능장애를 확진하지 않음

**위양성·위음성**

* 우는 아이는 고막이 붉어짐 - 발적만으로 중이염을 진단하지 않음
* tympanometry는 특이도는 높으나 민감도가 낮아 정상이어도 간헐적 이관 기능장애를 배제하지 못함
* 내 목소리·숨소리가 울리면(autophony) 개방성 이관 - 호흡에 따른 고막 움직임 관찰

## <mark style="color:green;">소리굽쇠 검사와 청력검사 (Rinne·Weber·순음청력검사)</mark>

**무엇을 보는가**

* 전음성 난청(외이·중이)과 감각신경성 난청(내이·청신경)의 구분
* 순음청력검사 : 주파수별 기도·골도 청력역치(dB HL)

**언제 시행하는가**

* 청력 저하, 귀 먹먹함, 이명, 어지럼 동반 청각 증상
* 갑작스러운 일측 청력 저하 : 돌발성 감각신경성 난청(SSNHL)을 먼저 의심 - 즉시 의뢰

**검사 방법**

* 512 ㎐ 소리굽쇠 사용
* Weber : 이마 중앙(또는 정수리)에 대고 어느 쪽에서 크게 들리는지
* Rinne : 유양돌기(골전도)에 대고 소리가 안 들리면 즉시 귀 앞(기도)으로 옮겨 다시 들리는지

**해석·절단값**

<table><thead><tr><th width="180">유형</th><th width="220">Weber</th><th>Rinne (환측)</th></tr></thead><tbody><tr><td><strong>정상</strong></td><td>가운데</td><td>기도 ＞ 골도 (양성)</td></tr><tr><td><strong>전음성 난청</strong></td><td>환측으로 편위</td><td>골도 ＞ 기도 (음성)</td></tr><tr><td><strong>감각신경성 난청</strong></td><td>건측으로 편위</td><td>기도 ＞ 골도 (양성; 둘 다 감소)</td></tr></tbody></table>

* 새로 생긴 일측 난청에서 Weber가 건측으로 편위하면 감각신경성 - SSNHL로 당일 이비인후과
* 순음청력검사 : 기도-골도 차이(air-bone gap)는 전음성, 기도·골도 모두 저하는 감각신경성

**위양성·위음성**

* Rinne는 기도-골도 차이가 약 20\~25 dB 이상일 때 음성이 되므로 경미한 전음성 난청은 놓침
* 귀지 전색은 가장 흔한 전음성 원인 - 이경으로 먼저 확인
* 저주파 전음성 난청처럼 보이는 상반고리관 피열증후군(SCDS) - VEMP·측두골 CT로 확진

## <mark style="color:green;">비강 내시경과 부비동 CT</mark>

**무엇을 보는가**

* 비강 내시경 : 비용종, 중비도 부종·농성 분비물, 비중격·비인두 병변, 출혈 부위
* 부비동 CT : 부비동 점막 염증, 해부학적 이상, 합병증(안와·두개내 파급), 치성 원인

**언제 시행하는가**

* 만성 비부비동염(CRS) 의심 : 객관적 염증 증거가 필요할 때 - 증상만으로 진단하지 않음
* 알레르기비염 등이 비전형적이거나 치료에 반응하지 않을 때, 비용종·종양 의심
* 일측성 반복 코피, 패킹·소작 후 반복 출혈
* 합병증 없는 급성 비부비동염(ARS)에는 CT를 하지 않음

**검사 방법**

* 비강 내시경 : 국소 마취·혈관수축제 분무 후 시행 (이비인후과)
* CT : 비조영 부비동 CT; 치성 원인이 의심되면 dental CT/CBCT

**해석·절단값**

* CRS 진단 : 12주 이상 코막힘·비루·안면 통증/압박감·후각 저하 중 2개 이상(코막힘 또는 비루 하나는 필수) + 내시경(비용종, 중비도 부종·농) 또는 CT의 객관적 염증 <mark style="color:$info;">\[EPOS 2020]</mark>
* 편측 중비도에 국한된 농 + 악취 + 상악 치아 시술력 : 치성 부비동염
* CT 적응 : 합병증 의심, CRS 객관적 확진·치료 불응 원인, 수술 전 평가

**위양성·위음성**

* 바이러스성 상기도 감염에서도 CT 점막 비후·저류가 흔함 - 영상만으로 세균성을 확정하지 않음
* 파노라마 X선은 치근단 병변을 놓칠 수 있음

## <mark style="color:green;">후두경 검사와 후두 미세진동 검사 (목쉼)</mark>

**무엇을 보는가**

* 후두경(laryngoscopy) : 성대 병변(결절·폴립·백반·종양), 성대 운동(마비), 후두 점막 상태 - 목쉼 원인의 1차 시각화 검사
* 후두 미세진동 검사(videostroboscopy) : 성대 점막 파동과 진동 대칭성 - 미세 점막 병변, 흉터, 성문 폐쇄부전

**언제 시행하는가**

* 목쉼이 4주까지 호전되지 않으면 후두경 또는 이비인후과 의뢰
* 기간과 무관하게 조기 : 흡연력, 최근 두경부·흉부 수술·기관삽관, 경부 종괴, 호흡곤란·stridor, 연하곤란·객혈, 직업적 음성 사용자
* 음성 치료 시작 전

**검사 방법**

* 경성 또는 연성(경비) 후두 내시경 - 이비인후과 외래

**해석·절단값**

* 소리 지른 직후 갑작스러운 실성 : 성대 출혈 의심 - 발성 중단, 당일 평가
* 기식성 음성 + 약한 기침 + 흡인 경향 : 성대 마비·노인성 발성장애
* 암 확진은 조직검사

**위양성·위음성**

* 후두경 소견만으로 인후두역류(LPR)를 확정하지 않음 - 후두 발적·부종은 비특이적
* 후두경 전에 목쉼 평가 목적의 CT·MRI는 하지 않음 (병변 확인 후 병기·마비 원인 평가에 사용)

## <mark style="color:green;">불면·주간졸림 평가 (수면일기·ISI·ESS·활동기록계)</mark>

**무엇을 보는가**

* 수면일기 : 취침·기상·밤중 각성 시각, 낮잠, 카페인·음주, 기분 - 수면 패턴과 일주기리듬
* 불면증 심각도 지수(ISI) : 불면의 중증도와 치료 반응
* 엡워스 졸음 척도(ESS) : 주간 졸림 - OSA·기면병·수면 부족의 단서
* 활동기록계(actigraphy) : 손목 장치로 1\~2주 수면-각성 패턴을 객관적으로 기록

**언제 시행하는가**

* 불면 호소 환자의 초기 평가와 인지행동치료(CBT-I)·약물 치료 경과 추적
* 일주기리듬 수면-각성장애 의심(늦게 자고 늦게 일어남, 너무 일찍 자고 깸)

**검사 방법**

* 수면일기 : 최소 1\~2주 기록
* ISI : 입면 곤란, 수면 유지 곤란, 조기 각성, 수면 만족도, 일상 기능 영향, 타인이 알아챈 정도, 수면 문제 걱정 7문항, 각 0\~4점
* ESS(K-ESS) : 독서, TV 시청, 공공장소 착석, 차량 동승, 오후 누워 휴식, 앉아서 대화, 점심 식후, 운전 중 정차 8가지 상황의 졸림을 각 0\~3점

**해석·절단값**

* ISI : 0\~7점 유의한 불면 없음, 8\~14점 역치하 불면, 15\~21점 중등도, 22\~28점 중증
* ESS : ＜10점 정상, 10\~13점 주간졸림, 14\~18점 중등도, ≥19점 심함 (대한수면의학회 기준)
* 심한 주간졸림이 두드러지면 불면장애보다 수면 부족, OSA, 기면병, 약물 영향을 먼저 평가

**위양성·위음성**

* 자기보고 척도로 OSA·기면병을 진단하지 않음
* 불면 환자는 수면 시간을 과소평가하는 경향 - 객관적 평가가 결정에 필요하면 활동기록계·수면다원검사
* ESS는 졸림을 자각하지 못하는 사람에서 낮게 나옴

***

## <mark style="color:green;">수면무호흡 선별과 수면검사 (STOP-Bang·수면다원검사·HSAT)</mark>

**무엇을 보는가**

* STOP-Bang : 폐쇄성 수면무호흡(OSA) 가능성을 8개 예/아니오 문항으로 선별
* 수면다원검사(PSG) : 뇌파·안구운동·근전도·호흡·산소포화도·심전도·다리 움직임을 밤새 기록 - OSA, 주기성 사지운동장애, 렘수면행동장애, 기면병(MSLT 병행) 진단
* 가정 수면무호흡검사(HSAT) : 호흡·산소포화도 중심의 간이 장비로 집에서 측정

**언제 시행하는가**

* 코골이, 목격된 무호흡, 주간 졸림, 비만, 치료 저항성 고혈압·AF·심부전·뇌졸중
* 불면 환자에서 진단이 불확실하거나 치료 반응이 없고 다른 수면장애가 의심될 때 PSG
* 하지불안증후군은 대부분 임상 진단 - OSA 동반 의심·비전형 증상일 때만 PSG
* HSAT : 중등도 이상 OSA 가능성이 높고 동반 질환(중등도 이상 심폐질환, 신경근육 질환, 다른 수면장애)이 없는 성인

**검사 방법**

* STOP-Bang 문항
  * Snoring 큰 코골이 · Tired 주간 피로·졸림 · Observed 목격된 무호흡 · Pressure 고혈압
  * BMI ＞35 ㎏/㎡ · Age ＞50세 · Neck 목둘레 ＞40 ㎝ · Gender 남성
* PSG는 수면검사실에서 하룻밤 시행

**해석·절단값**

* STOP-Bang : 0\~2점 저위험, 3\~4점 중간 위험, 5\~8점 고위험
* 무호흡-저호흡 지수(AHI, 수면 1시간당 10초 이상 무호흡·저호흡 횟수) : 5\~14 경증, 15\~29 중등도, ≥30 중증
* 성인의 주기성 사지운동장애 : PLMI ＞15회/시간에 임상적으로 유의한 수면장애 또는 주간 기능 저하가 동반되고, 하지불안증후군·치료하지 않은 OSA 등으로 더 잘 설명되지 않을 때 진단 <mark style="color:$info;">\[J Clin Sleep Med 2025]</mark>

**위양성·위음성**

* STOP-Bang은 민감도가 높고 특이도가 낮음 - 선별도구이며 확진은 PSG 또는 HSAT
* 일반적인 HSAT는 수면시간 대신 모니터링 시간을 분모로 하는 호흡 사건 지수(REI)를 보고. PSG의 AHI보다 낮게 추정될 수 있음. 진단 목적의 단회 HSAT가 음성·불확정이거나 기술적으로 부적절하면 PSG 시행 <mark style="color:$info;">\[J Clin Sleep Med 2017]</mark>
* 마른 체형·여성·젊은 환자의 OSA를 놓치기 쉬움

**급여**

* 수면다원검사는 2018년부터 OSA 등 수면장애 의심 시 급여 기준에 따라 급여 (횟수·적응증 조건 확인)

***

## <mark style="color:green;">구강 칸디다 검사 (KOH 도말·배양·생검)</mark>

**무엇을 보는가**

* KOH 현미경 : 출아효모, 가성균사 또는 균사
* 배양·감수성 : 균종(_C. albicans_ 외 _C. glabrata_ 등)과 항진균제 감수성
* 생검 : 조직 내 칸디다 침윤, 이형성·백반증 감별

**언제 시행하는가**

* 대부분 임상 진단 - 거즈로 닦이는 백색 위막과 그 아래 발적·점상출혈
* KOH : 비전형적이거나 홍반형(위막 없이 혀 발적·통증)일 때
* 배양·감수성 : 치료 실패, 재발, 내성 의심
* 생검 : 닦이지 않는 지속성 백색 병변, 경결·궤양·적백색 변화 - 항진균제 반응을 기다리지 않음

**검사 방법**

* 병변을 설압자로 긁어 KOH 도말; 틀니를 쓰면 틀니 점막면도 확인
* 반복·난치성이면 순응도·흡입 스테로이드 사용법·틀니 관리를 먼저 확인한 뒤 혈당·A1C, CBC, (위험이 있으면) HIV 검사

**해석·절단값**

* 칸디다는 정상 상재균 - KOH·배양 양성만으로 감염을 확진하지 않고 임상 병변과 함께 해석
* 배양에서 비albicans 균종·fluconazole 내성이면 감수성에 따라 약제 선택 (감염내과 협진)

**위양성·위음성**

* 백반증·편평태선을 칸디다증으로 오진 - 닦이지 않으면 조기 의뢰·생검
* 항진균제 사용 후 채취하면 위음성

***

## <mark style="color:green;">구강건조 평가와 타액분비량 검사 (Fox 4문항·CODS·sialometry)</mark>

**무엇을 보는가**

* 구강건조 증상(xerostomia)과 객관적 타액분비저하(hyposalivation)를 구분하고 원인(약물, 쇼그렌병, 당뇨병, 탈수, 방사선 치료)을 평가

**언제 시행하는가**

* 입마름, 마른 음식을 삼키기 어려움, 구강작열감, 다발성 치경부 우식, 반복 구강 칸디다증
* 안구건조·침샘 종창·관절통 동반 시 쇼그렌병 평가

**검사 방법**

* Fox 4문항 : ① 식사할 때 입이 마른가 ② 음식을 삼키기 어려운가 ③ 마른 음식을 삼킬 때 물이 필요한가 ④ 입안의 침이 너무 적다고 느끼는가 - 하나 이상 양성이면 추가 평가
* 진찰 : 치경(구강 거울)이 협점막·혀에 붙음, 구강저 침 고임 소실, 혀 유두 위축, 치경부 우식, 침샘 촉진
  * CODS(Challacombe 척도) : 10개 소견을 각 1점으로 합산 (0\~10점)
* sialometry : 측정 1\~2시간 전 금식·금연·양치 금지
  * 비자극 전타액 : 5\~15분간 자연스럽게 흘린 침을 모음
  * 자극 전타액 : 파라핀 왁스를 씹으며 5분간 모음
* 원인 검사(선택) : 혈당·A1C, 신기능·전해질, ANA·anti-SSA(Ro) ± anti-SSB(La), CBC, ESR/CRP, TSH, HCV·HIV, IgG4

**해석·절단값**

* 비자극 전타액 ≤0.1 ㎖/분, 자극 전타액 ≤0.7 ㎖/분 : 타액분비저하
* CODS : 점수가 높을수록 건조가 심함 (1\~3 경도, 4\~6 중등도, 7\~10 중증)
* 쇼그렌병 2016 ACR/EULAR 분류기준 : anti-SSA(Ro) 양성 3점, 입술 소타액선 생검 focus score ≥1 3점, Ocular Staining Score ≥5(또는 van Bijsterveld ≥4) 1점, Schirmer ≤5 ㎜/5분 1점, 비자극 타액 ≤0.1 ㎖/분 1점 - 합 ≥4점이면 분류기준 충족

**위양성·위음성**

* 증상만으로 타액분비저하를 확진하지 않음 - 분비량이 정상인 구강건조감도 흔함
* 항콜린성 약물은 측정 결과를 낮춤 - 분류기준 적용 전 충분한 휴약
* anti-SSA 음성만으로 쇼그렌병을 배제하지 않음; anti-SSB 단독 양성은 분류기준 항목이 아님
* 측정 조건·일중 변동으로 오차가 큼 - 같은 조건에서 반복
