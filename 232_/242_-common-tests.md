## <mark style="color:green;">빈혈 평가 (CBC 지수·망상적혈구·말초혈액도말·용혈 검사)</mark>

**무엇을 보는가**

* Hb·Hct, 적혈구 지수(MCV·MCH·MCHC), RDW : 빈혈의 유무와 형태학적 분류
* 절대 망상적혈구 수·RPI : 골수 생성 반응 - 생성 저하와 소실(출혈·용혈)을 나누는 첫 분기
* 말초혈액도말 : 적혈구 형태, 과분엽 호중구, 파편적혈구, 미성숙 세포
* 용혈 검사 : LDH, 간접 빌리루빈, haptoglobin, DAT

**언제 시행하는가**

* 피로·호흡곤란·창백, 출혈력, 만성질환에서 빈혈이 의심될 때
* 무증상 일반 성인의 일률적 선별 간격은 확립되지 않음 - 임신은 산전 기준에 따라 초기 CBC와 경과 중 재평가

**검사 방법**

* 초기 : CBC 감별, 적혈구 지수, RDW, 혈소판, 절대 망상적혈구(± RPI), 말초혈액도말, 철 검사(☞ 철 상태 검사), Cr/eGFR
* 선택 : LFT, TSH, CRP/ESR, Vit B12·엽산, LDH·빌리루빈·haptoglobin·DAT, 소변검사
* 과거 CBC와 비교해 감소 속도를 확인

**해석·절단값**

* 빈혈 정의 (WHO 2024, 해수면, 15\~65세) : 비임신 여성 Hb ＜12 g/㎗, 남성 ＜13 g/㎗; 임신 1·3삼분기 ＜11, 2삼분기 ＜10.5 g/㎗
* 65세 초과는 WHO 별도 절단값이 없음 - 검사실 참고범위와 임상 맥락으로 판단하고 정상 노화로 넘기지 않음
* RPI = (망상적혈구% × 환자 Hct ÷ 정상 Hct) ÷ 성숙보정계수(Hct에 따라 1\~3) : ＜2 생성 부적절, 약 2\~3 이상 출혈·용혈에 대한 적절한 반응

* Mentzer index = MCV(fL) ÷ RBC(10⁶/㎕) : ＜13 thalassemia trait, ≥13 철결핍 쪽 - 선별 보조지표

**위양성·위음성**

* 철결핍과 B12·엽산 결핍이 함께 있으면 MCV가 정상일 수 있음; 망상적혈구 증가·한랭응집소는 MCV를 높임
* 급성 출혈·용혈 직후에는 망상적혈구 반응이 지연될 수 있음
* RDW·Mentzer index만으로 확진하지 않음; α-thalassemia trait는 Hb 전기영동이 정상일 수 있음
* haptoglobin은 간질환에서 낮고 염증에서 정상일 수 있음; DAT 양성만으로 자가면역 용혈을 확진하지 않으며 DAT 음성 자가면역 용혈도 드물게 있음
* 위장관 수술·영양실조·고용량 아연 보충 후 설명되지 않는 빈혈·호중구감소·신경 증상 : 구리·ceruloplasmin (구리 결핍은 MDS와 유사)
* 경미하고 안정적인 단독 빈혈의 고령자에게 일률적 골수검사보다 CBC 추적; 범혈구감소·비정상 도말·진행성 빈혈은 혈액내과
* 대변잠혈·FIT 음성만으로 위장관 출혈을 배제하지 않음

## <mark style="color:green;">철 상태 검사 (ferritin·TSAT)</mark>

**무엇을 보는가**

* ferritin : 체내 철 저장량 - 낮으면 철결핍에 특이적이나 급성기 반응 물질이라 염증에서 오름
* 트랜스페린 포화도(TSAT = 혈청 철 ÷ TIBC × 100) : 조혈에 쓸 수 있는 철 - 염증 상태에서 철결핍 판단에 유용
* 혈청 철, TIBC

**언제 시행하는가**

* 하지불안증후군 : 임상적으로 유의한 모든 RLS에서 ferritin과 TSAT 측정
* 불면증·피로·산후 우울에서 빈혈·철결핍이 의심될 때, 탈모
* 철결핍빈혈 의심과 원인 평가 (☞ 빈혈 챕터)

**검사 방법**

* 아침 공복 채혈; 철분 함유 음식·보충제는 최소 24시간 전부터 피함 <mark style="color:$info;">\[AASM 2025]</mark>, 경구 철분제는 48시간 전 중단 <mark style="color:$info;">\[RLS Foundation 2026]</mark>

**해석·절단값**

* RLS의 철 보충 기준 <mark style="color:$info;">\[AASM 2025]</mark>
  * ferritin ≤75 ng/㎖ 또는 TSAT ＜20% : 경구 또는 정맥 철분 고려
  * ferritin 75\~100 ng/㎖ : 정맥 철분 고려
  * ferritin ＞300 ng/㎖ 또는 TSAT ≥45% : 철 과부하 위험으로 정맥 철분 투여하지 않음
* TSAT ≥45%가 반복되면 철분 투여를 보류하고 간질환·수혈력·가족력 평가, 필요하면 혈색소증 유전자 검사·전문의 의뢰
* 철결핍빈혈 (성인)
  * ferritin ＜15 ng/㎖ 저장철 고갈을 강하게 시사, ＜30 ng/㎖ 철결핍 가능성 높음
  * 빈혈 성인의 위장관 평가 맥락에서 AGA는 ＜45 ng/㎖를 진단 절단값으로 권고 <mark style="color:$info;">\[Gastroenterology 2020]</mark> - 비빈혈성 철결핍·소아·임신·CKD에 일률 적용하지 않음
  * 철분제 시작 전에 가능하면 ferritin을 채혈
* 심부전 : TSAT ＜20% 중심의 철결핍 정의를 지지, ferritin도 함께 측정하여 저장철·과부하 평가 <mark style="color:$info;">\[ESC 2026]</mark>
* 철결핍이 확인되면 원인(월경과다, 위장관 출혈·병변, 흡수장애, 채식, 잦은 헌혈, 산 억제제)을 평가

**위양성·위음성**

* ferritin은 측정법에 따라 차이가 큼 - RLS Foundation 기준값 75/100/300 ng/㎖는 Roche 측정법에서 약 121/158/457 ng/㎖ <mark style="color:$info;">\[RLS Foundation 2026]</mark>
* 염증·감염·간질환·악성종양에서 ferritin 거짓 상승 - 이때는 TSAT ＜20%가 철 부족을 더 잘 반영
* 최근 철분 복용·식사 후 채혈은 혈청 철·TSAT를 일시적으로 올림

## <mark style="color:green;">출혈 경향 검사 (CBC·PT/INR·aPTT·von Willebrand 검사)</mark>

**무엇을 보는가**

* 혈소판 수(CBC), 외인성·공통 경로(PT/INR), 내인성·공통 경로(aPTT) - 출혈의 혈액학적 원인과 항응고 효과

**언제 시행하는가**

* 반복·다량 코피, 반복되거나 광범위한 결막하출혈, 쉽게 생기는 멍, 잇몸 출혈, 월경과다
* warfarin 복용자의 출혈 (INR), 수술·시술 전 출혈 병력이 있을 때
* 단순 전방 코피, 단발성 결막하출혈은 일반적으로 검사 불필요

**검사 방법**

* 출혈 병력(어린 시절부터, 발치·수술 후, 월경과다)과 가족력, 항혈전제·NSAID·보충제 복용을 먼저 확인
* 다량 출혈·불안정이면 혈액형·교차시험, fibrinogen 추가

**해석·절단값**

* PT/INR 연장 : warfarin, 비타민 K 결핍, 간질환
* aPTT 단독 연장 : heparin, 혈우병(VIII·IX 결핍), lupus anticoagulant(출혈보다 혈전)
* warfarin 복용자는 목표 INR과 비교
* DOAC의 정량은 약제별 보정 anti-Xa 또는 희석 thrombin time - 상급기관 판단; PT·aPTT로 효과를 판단하지 않음
* 혈소판 감소 : 원인(ITP, 약물, 간질환·비장 비대, 골수 질환) 평가

**위양성·위음성**

* PT·aPTT·혈소판이 정상이어도 von Willebrand병, 혈소판 기능 이상은 배제되지 않음 - 출혈 병력·가족력이 강하면 vWF 항원·활성도 등 추가 평가, 혈액내과 의뢰
* 항혈전제는 검사 결과만으로 임의 중단하지 않음
* 채혈 튜브의 혈액량 부족·헤파린 오염은 응고 시간을 거짓으로 늘림

## <mark style="color:green;">항응고제 모니터링 (warfarin INR·DOAC 추적검사·UFH aPTT·anti-Xa)</mark>

**무엇을 보는가**

* INR : warfarin 항응고 강도
* DOAC 추적 : CBC, CrCl(Cockcroft-Gault), 간기능, 체중 - 용량 적정성과 출혈 위험
* aPTT·anti-Xa : 비분획 헤파린(UFH) 모니터링

**언제 시행하는가**

* 항응고 시작 전 기초 검사 : CBC, Cr·CrCl, 간기능, 체중
* warfarin : 시작·용량 변경·상호작용 약물 추가 후, 안정화 후 흔히 약 4주 간격
* DOAC : 정기 INR은 필요 없으나 정기 추적은 필요

**검사 방법**

* DOAC 추적 간격 <mark style="color:$info;">\[Europace 2021]</mark>
  * 안정된 환자 : CBC·CrCl·간기능 최소 연 1회
  * ≥75세(특히 dabigatran)·허약 : 약 4개월마다
  * CrCl ≤60 ㎖/min : 신기능 재검 간격 'CrCl ÷ 10 개월' 이내 (예 : CrCl 40이면 4개월)
  * 탈수·감염·급성 신손상, 출혈, 새 상호작용 약물 : 예정일을 기다리지 않고 재평가

**해석·절단값**

* warfarin 목표 INR : 대부분 2.0\~3.0; 기계판막은 위치·종류·위험인자에 따라 다름
* 급성 VTE를 warfarin으로 치료하면 비경구 항응고제를 최소 5일, INR ≥2.0이 24시간 이상 유지될 때까지 중첩
* 출혈 없는 INR 4.5\~10 : warfarin 일시 보류·원인 교정; INR ＞10 또는 출혈 동반 INR 상승은 당일 평가
* 주요 수술 전 INR 흔히 ＜1.5 목표

**위양성·위음성**

* DOAC 용량은 eGFR이 아니라 CrCl 기준 - 두 값을 바꿔 쓰지 않음 (☞ 신기능 지표)
* 근육량이 적은 고령자는 크레아티닌 기반 신기능이 과대평가될 수 있음
* 일반 PT/INR·aPTT로 DOAC 효과를 정량하지 않음; UFH에는 INR을 쓰지 않음

## <mark style="color:green;">C-반응단백 CRP (현장검사 포함)</mark>

**무엇을 보는가**

* 감염·염증 시 IL-6 자극으로 간에서 만드는 급성기 단백
  * 자극 후 6\~8시간에 오르기 시작해 약 48시간에 최고치에 이름
* 세균·바이러스·비감염성 염증을 구별하지 못하는 비특이적 지표

**언제 시행하는가**

* 하기도감염에서 진찰 후에도 항생제 필요성이 불확실할 때 (16세 이상) <mark style="color:$info;">\[NICE 2023]</mark>
  * 합병증 없는 급성 기관지염의 routine 검사, 소아 기준, 확진된 COVID-19에는 적용하지 않음
* 폐렴의 중증도·치료 반응 평가 (영상 소견과 함께)
* 입원 폐렴 환자에서 치료 3\~4일째 반응이 우려될 때 재측정 <mark style="color:$info;">\[NICE 2025]</mark>

**검사 방법**

* 정맥혈 검사 또는 손가락 끝 채혈 현장검사(POCT, 수 분 내 결과)
* **단위 확인** : 지침의 절단값은 ㎎/L이나 국내 검사실은 ㎎/㎗로 보고하는 곳이 많음 (20 ㎎/L = 2 ㎎/㎗, 100 ㎎/L = 10 ㎎/㎗)

**해석·절단값**

* 하기도감염 항생제 판단 <mark style="color:$info;">\[NICE 2023]</mark>

* 이미 세균성 CAP가 의심되는 환자에서 낮은 CRP만으로 항생제를 보류하지 않음

**위양성·위음성**

* 낮게 나오는 경우 : 증상 발생 초기(12시간 이내), 고령자·면역 저하자, 중증 간부전, tocilizumab 등 IL-6 억제제 사용
* 감염 없이 높은 경우 : 수술·외상·화상, 자가면역질환, 악성 종양, 심근경색, 비만(경도 상승)

## <mark style="color:green;">신기능 지표 (eGFR·CrCl·cystatin C)</mark>

**무엇을 보는가**

* eGFR : 혈청 크레아티닌(± cystatin C)·나이·성별로 추정한 사구체여과율 - CKD 진단·병기, 약물 용량 조절
* CrCl (Cockcroft-Gault) : 크레아티닌 청소율 추정 - 여러 약물(특히 NOAC)의 허가 용량 기준
* cystatin C : 근육량의 영향을 덜 받는 신기능 표지자

**언제 시행하는가**

* 고혈압·당뇨병·심부전·심혈관질환 진단 시와 추적 중 (K와 함께 적어도 연 1\~2회)
* 신배설 약물(NOAC, metformin, SGLT2 억제제, MRA, digoxin 등)의 시작·용량 결정
* cystatin C : 근육량이 매우 많거나(젊은 근육질) 적은(노인, 근감소, 절단, 와병) 환자에서 크레아티닌 eGFR을 믿기 어려울 때 <mark style="color:$info;">\[KDIGO 2024]</mark>

**검사 방법**

* eGFR : 검사실이 CKD-EPI 2021(인종 항목 제외) 식으로 자동 보고하는 경우가 많음
* CrCl (Cockcroft-Gault) = (140 − 나이) × 체중(㎏) ÷ (72 × Cr ㎎/㎗) × (여성 0.85) - 단위 ㎖/min, 체표면적 보정 없음
* eGFRcr-cys : 크레아티닌과 cystatin C를 함께 쓴 식이 가장 정확

**해석·절단값**

* CKD : eGFR ＜60 ㎖/min/1.73㎡ 또는 알부민뇨 등 신손상 표지가 3개월 이상 지속
* GFR 병기 : G1 ≥90, G2 60\~89, G3a 45\~59, G3b 30\~44, G4 15\~29, G5 ＜15
* 약물 용량은 해당 약의 허가 기준(eGFR인지 CrCl인지)을 확인 - NOAC은 CrCl 기준

**위양성·위음성**

* 급성 신손상, 탈수 등 신기능이 변하는 중에는 eGFR이 부정확 - 안정 상태에서 재검
* 크레아티닌 : 근육량, 고기 섭취, cimetidine·trimethoprim(세뇨관 분비 억제)의 영향
* cystatin C : 갑상선기능 이상, 고용량 스테로이드, 염증·비만의 영향
* Cockcroft-Gault는 비만에서 실제 체중을 쓰면 과대평가, 고령·저체중에서는 오차가 큼

**급여**

* 크레아티닌·eGFR은 급여; cystatin C는 급여 기준 확인 필요

## <mark style="color:green;">소변검사 해석 (시험지봉·요침사 현미경)</mark>

**무엇을 보는가**

* 시험지봉 : 잠혈, 단백, 포도당, 케톤, 백혈구 에스테라아제, 아질산염, 빌리루빈, 우로빌리노겐, pH, 비중 - 반정량 선별
* 요침사 현미경 : 적혈구(수·형태), 백혈구, 원주(cast), 결정, 세균, 상피세포

**언제 시행하는가**

* CKD 위험군(당뇨병, 고혈압, 심혈관질환, AKI 병력, 가족력, 신독성 약물)의 평가 - eGFR·UACR과 함께
* 혈뇨·배뇨 증상·옆구리 통증·부종·AKI 평가
* 위험인자 없는 무증상 일반인의 일률적 시험지봉 선별은 이득이 확립되지 않음
* 고령자·도뇨관 유치자에서 증상 없이 UTI 진단 목적으로 시행하지 않음

**검사 방법**

* 아침 첫 중간뇨 우선(알부민뇨), 혈뇨 확인은 신선한 검체 - 격렬한 운동·성행위 직후, 월경 중, 발열·증상성 UTI 중 검체는 피함
* 남성은 포피를 젖히고, 여성은 음순을 벌려 오염 방지; 채취 후 2시간 이내 검사 (지연되면 검사실 지침대로 냉장)
* STI 핵산검사(NAAT)는 중간뇨가 아니라 첫 부분뇨 - 검사별 지침 확인
* 24시간 소변 : 아침 첫 소변은 버리고 시각 기록 → 이후 모든 소변(배변 시 포함) 수집 → 다음 날 같은 시각 마지막 소변까지 - 한 번이라도 빠뜨리면 다시 채취

**해석·절단값**

* 시험지봉 잠혈 양성은 반드시 현미경으로 확인 : RBC 있음 = 진성 혈뇨, RBC 없음 = 혈색소뇨·근색소뇨(또는 희석·알칼리뇨의 용혈)
* 성인 현미경적 혈뇨 : 적절한 검체에서 RBC ≥3/HPF
* 백혈구 에스테라아제·아질산염 모두 양성이면 UTI 가능성이 높으나, 아질산염 음성으로 UTI를 배제하지 못함
* 단백 양성은 UACR 또는 UPCR로 정량 (☞ 단백뇨 정량)
* 요침사 소견

* 요중 호산구는 간질성 신염의 확진·배제에 쓰지 않음

## <mark style="color:green;">간기능검사 해석 (ALT·AST·ALP·GGT·빌리루빈)</mark>

**무엇을 보는가**

* ALT·AST : 간세포 손상 (ALT가 간 특이적, AST는 근육·적혈구에도 있음)
* ALP·GGT : 담즙정체 (ALP는 뼈·태반에도 있어 GGT로 간 기원 확인)
* 빌리루빈(총·직접), albumin, PT/INR, 혈소판 : 간 합성 기능과 문맥압항진 - 진행된 간질환의 지표

**언제 시행하는가**

* 간질환 위험(음주, 비만·당뇨병, 바이러스 간염 위험) 평가, 간독성 약물 투여 전후, 황달·피로·우상복부 통증

**검사 방법**

* 손상 양상 분류 : R = (ALT ÷ ALT 정상 상한) ÷ (ALP ÷ ALP 정상 상한)
  * R ≥5 간세포형, R ≤2 담즙정체형, 2\~5 혼합형

**해석·절단값**

* ALT 정상 상한 : 대한간학회 남 34 IU/L, 여 30 IU/L <mark style="color:$info;">\[대한간학회 2026]</mark> - 검사실 정상 범위 안이어도 고위험군은 섬유화 평가
* 양상별 주요 원인

<table><thead><tr><th width="210">양상</th><th>주요 원인</th></tr></thead><tbody><tr><td><strong>경미한 상승 (＜5배)</strong></td><td>MASLD·알코올(가장 흔함), 약물·허브, B·C형간염, 혈색소증, 자가면역간염, Wilson병, α₁-antitrypsin 결핍; 간외 원인 - 갑상선 이상, 셀리악병, 용혈, 근육질환</td></tr><tr><td><strong>현저한 상승 (＞1,000 U/L)</strong></td><td>허혈성 간염, 급성 바이러스 간염, 약물(acetaminophen 등), 급성 담도 폐쇄 초기</td></tr><tr><td><strong>AST/ALT ＞1.5~2</strong></td><td>알코올 간질환, 진행된 섬유화·간경변 (단독 진단 기준은 아님)</td></tr><tr><td><strong>ALP·GGT 상승</strong></td><td>담도 폐쇄, 원발 담즙성 담관염, 침윤성 간질환, 약물 - 초음파로 담관 확장 확인</td></tr><tr><td><strong>ALP 단독 상승 + GGT 정상</strong></td><td>뼈(성장기, 골절, Paget병, 골전이), 임신</td></tr><tr><td><strong>간접 빌리루빈 단독 상승</strong></td><td>Gilbert 증후군 (금식·질병 시 상승, 다른 간기능 정상), 용혈</td></tr></tbody></table>

* 경미한 상승의 1차 감별 검사 : HBsAg, anti-HCV, CBC·혈소판, albumin, 철·TIBC·ferritin, 대사 위험(허리둘레·혈당·지질), 복부 초음파

**위양성·위음성**

* 간효소가 정상이어도 MASH·진행된 섬유화·간경변이 있을 수 있음 - 간효소로 섬유화 정도를 판단하지 않음
* 격한 운동·근육 손상은 AST(± ALT)를 올림 - CK로 확인
* GGT는 비만·약물·음주에서 비특이적으로 오르며 정상이어도 음주를 배제하지 못함
