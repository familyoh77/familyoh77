# 임상 검사

{% hint style="info" %}
* 각 챕터에 나오는 검사와 진료실 평가 도구를 계통별로 모아 해설한 참고 파트임. 오래전 수련 이후 새로 도입되었거나 해석 기준이 바뀐 검사를 중심으로 수록함
* 항목 구성 : 무엇을 보는가 / 언제 시행하는가 / 검사 방법 / 해석·절단값 / 위양성·위음성 / 급여
* 질환별 검사 선택과 후속 조치는 해당 질환 챕터에서, 검사 방법과 결과 해석은 이 파트에서 확인함
* 검사실 결과지에서 검사법·단위·참고구간을 확인. 진단·배제·의뢰에 쓰는 임상 절단값은 해당 검사법과 환자군에서 검증된 기준을 적용하며, 검사실 참고구간과 구분함
* '소아'로 표시하지 않은 기준은 성인 기준임
{% endhint %}

## <mark style="color:green;">검사 해석의 기본</mark>

* 검사 결과의 의미는 검사 전 확률(사전확률)에 따라 달라짐
  * 같은 검사에서 양성이 나와도 사전확률이 낮을수록 실제로 질환이 있을 가능성(양성예측도)은 낮아짐
  * 사전확률이 높은 환자에서는 음성 결과만으로 질환을 배제하지 않음
* 배제(rule-out) 검사와 확진(rule-in) 검사를 구분
  * 민감도가 높은 검사의 음성은 배제에 유용 (예: 사전확률이 낮은 환자의 D-dimer 음성, 외래 심부전 의심 환자에서 해당 진료 경로의 배제 기준 미만인 NT-proBNP)
  * 특이도가 높은 검사의 양성은 확진에 유용
  * 하나의 절단값으로 배제와 확진을 함께 하기는 어려워, 배제 기준과 확진 기준을 따로 두고 그 사이를 회색 지대(gray zone)로 남기는 검사가 많음
* 우도비(likelihood ratio, LR)
  * 양성 LR ＞10 또는 음성 LR ＜0.1이면 사전확률을 크게 바꿈
  * LR 2\~5 또는 0.2\~0.5는 사전확률을 조금만 바꿈
* 연속 측정
  * 같은 검사법(assay)·같은 검사기관에서 시행
  * 측정 오차와 개인 내 변동보다 큰 변화만 의미 있게 해석
* 단위 확인 : 같은 검사라도 검사기관마다 단위·표준화 방식이 다를 수 있음 (예: D-dimer의 FEU/DDU)
* 정상 결과가 질환을 배제하지 못하는 상황(조기 시점, 치료 중, 증상·소견이 뚜렷하지 않은 경우 등)은 각 항목의 '위양성·위음성'에서 확인
