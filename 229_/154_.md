# 피부 병소의 표현

### 피부 병변의 기술

Primary (Basic) Lesion

| 영어 용어                                   | 한글 용어 | 정의                          |
| --------------------------------------- | ----- | --------------------------- |
| [**Macule**](ca://s?q=Explain_macule)   | 반점    | 평평한(만져지지 않는) 변색 병소 (≤5 mm)  |
| [**Patch**](ca://s?q=Explain_patch)     | 반     | 평평한 변색 병소 (>5 mm)           |
| [**Papule**](ca://s?q=Explain_papule)   | 구진    | 고형의 융기 병소 (≤5 mm)           |
| [**Plaque**](ca://s?q=Explain_plaque)   | 판     | 평평한 융기 병소 (>5 mm), 종종 구진 융합 |
| [**Nodule**](ca://s?q=Explain_nodule)   | 결절    | 고형의 둥근 융기 병소 (0.5\~5 cm)    |
| [**Wheal**](ca://s?q=Explain_wheal)     | 팽진    | 홍반성 부종성 구진/판                |
| [**Pustule**](ca://s?q=Explain_pustule) | 농포    | 고름이 채워진 융기                  |
| [**Vesicle**](ca://s?q=Explain_vesicle) | 소수포   | 액체로 채워진 융기 (≤5 mm)          |
| [**Bulla**](ca://s?q=Explain_bulla)     | 물집    | 액체로 채워진 융기 (>5 mm)          |

Secondary (Sequential) Lesion

| 영어 용어                                                   | 한글 용어 | 정의                 |
| ------------------------------------------------------- | ----- | ------------------ |
| [**Scale**](ca://s?q=Explain_scale)                     | 비늘    | 각질의 과도한 축적         |
| [**Crust**](ca://s?q=Explain_crust)                     | 딱지    | 건조된 혈액/혈청/고름       |
| [**Erosion**](ca://s?q=Explain_erosion)                 | 미란    | 표피의 표재성 결손         |
| [**Ulcer**](ca://s?q=Explain_ulcer)                     | 궤양    | 표피 및 진피의 결손        |
| [**Fissure**](ca://s?q=Explain_fissure)                 | 열창    | 선형 결손              |
| [**Atrophy**](ca://s?q=Explain_atrophy)                 | 위축    | 피부 얇아짐으로 인한 함몰     |
| [**Excoriation**](ca://s?q=Explain_excoriation)         | 찰상    | 긁힘에 의한 미란          |
| [**Lichenification**](ca://s?q=Explain_lichenification) | 태선화   | 피부 주름이 뚜렷해진 두꺼운 상태 |

_\*출처에 따라 병소 크기의 정의가 다소 다름._ \
_Ref. Rakel Family medicine 9th ed. 2016. Table 33-1._

* 흉터(scar) : 외상 또는 염증 후 2차적으로 발생한 피부 변화
* 가피(eschar) : 검은 딱지로 덮인 괴사성 병소
* 모세혈관확장(telangiectasia) : 확장된 표재성 혈관
* 출혈점(petechia) : ＜3 ㎜의 만져지지 않는 평평한 자색반
* 반상출혈, 얼룩출혈(ecchymosis) : ≥3 ㎜의 만져지지 않는 평평한 자색반
* 촉지자색반(palpable purpura) : 혈관 염증에 의한 융기된 자색반
* 종양(tumor) : 지름 ≥5 ㎝의 고형의 융기 병소

### 멜라노 병변(melanocytic lesion)의 악성 감별

* 양성 소견 : 대칭, 명확한 경계, 균일한 색조, 직경 ≤6 ㎜, 크기 변화 없음
* 악성 의심 소견 : 비대칭, 불확실한 경계, 고르지 못한 색조, 직경 ＞6 ㎜, 점차 커짐
